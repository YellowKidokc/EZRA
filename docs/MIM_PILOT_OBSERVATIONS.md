# MIM pilot — observed names and unresolved editions

Reference snapshot: November 20, 2026, from the read-only MIM Names and Connections register. These are scope/name observations, not source authority decisions or expected counts for a future scan.

## Counts

- 21 paper folders, MIM.00 through MIM.20.
- 11 loose root manuscript candidates, MIM.00 through MIM.10.
- 27 dossier manuscript candidates: 21 base files plus six numbered-suffix variants.
- 38 manuscript candidates in the bounded main-file extraction.
- 73,254 inventoried files and 1,858 folders including the series root, within declared scan exclusions.
- MIM.06 physically contains 44,476 files. This does not establish that every nested item semantically belongs to that paper.

The statement “every paper exists twice” is not supported by this register: loose root counterparts were observed for eleven positions. The review said “seven” numbered duplicates but named six; the observed list contains six.

Shared declared IDs make these identity/version candidates, not safe automatic merges. Retain every source, compare bytes/predicates/premises and distinguish an intentional revision from a mistaken copied ID. Do not select the root copy, dossier copy, longest file or latest timestamp as keeper by default.

The scanner should be able to inventory such conflicts without first requiring a human to reorganize the corpus. Record unresolved observations and report them for review.

## Large research scope

MIM.06's large physical tree includes research and YouTube material. The names register used path/type tags, not semantic review of every transcript. Future count reports must distinguish manuscripts, supporting sources, machine artifacts and physical duplicates without claiming completed processing.

Use synthetic fixtures with analogous duplicate IDs, missing headers and copied research trees in CI. Do not commit private manuscripts, real network paths, source inventories or private proof/audit packets into this public repository.
